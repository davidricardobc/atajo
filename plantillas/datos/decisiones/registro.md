# Registro de decisiones

Solo se agrega, nunca se edita ni se borra. Si una decisión cambia, se agrega la nueva y se enlaza a la anterior. El agente propone registrar cada vez que tomas una decisión; también anota aquí las que toma solo cuando no estás (nivel equilibrado o autónomo).

Formato de cada entrada:

```
## AAAA-MM-DD · Título corto

- Decisión: qué se decidió, en una frase.
- Por qué: las razones, con datos si los hay.
- Alternativas que se miraron:
- Qué la cambiaría: la señal que haría volver a decidir.
- Quién decidió: tú o el agente (y por qué no esperó).
- Enlaces: [[nota]] relacionada, prioridad a la que sirve.
```

## 2026-10-06 · Instalar Atajo

- Decisión: instalar Atajo como sistema operativo personal sobre Claude Code.
- Por qué: tener continuidad entre sesiones, foco en tres prioridades y reglas claras de autonomía.
- Alternativas que se miraron: seguir con conversaciones sueltas sin memoria compartida.
- Qué la cambiaría: que en 30 días `bitacora/ahora.md` no se esté actualizando.
- Quién decidió: la persona que instaló el kit. `/arranque` agrega una entrada nueva con el nombre, la fecha y el nivel de autonomía elegido; esta no se edita.
- Enlaces: [[prioridades]], [[quien-soy]].
